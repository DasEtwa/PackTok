# M5

The first paired A/C Transformer pilot completed 2,000 updates per variant on one seed. Both used the same 14.68M-parameter FP32 architecture, initialization and target-position budget. Validation was A 2.572964850 versus C 2.597469229 bits per raw byte (C−A +0.024504380); A saw 7,575,564 sampled training bytes and C 6,946,291. The result is exploratory, not statistical proof. The frozen TEST split was scored and is not an untouched holdout for revised experiments.
